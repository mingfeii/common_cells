# 论文与代码对照

## 1. 来源与页码

本文使用工程根目录的两份用户提供 PDF：

1. `CummingsSNUG2002SJ_FIFO1_rev1_2.pdf`，正文标题为 *Simulation and Synthesis Techniques for Asynchronous FIFO Design*，Clifford E. Cummings，Rev 1.2，最后更新 2005-06-16。该文件前面多了一页 ResearchGate 封面，所以 **PDF 文件页码 = 正文印刷页码 + 1**。
2. `Simulation and Synthesis Techniques for Asynchronous FIFO Design with Asynchronous Pointer Comparisons.pdf`，Clifford E. Cummings / Peter Alfke，Rev 1.2，最后更新 2005-06-20。**PDF 文件页码与正文印刷页码一致**。

后续“正文页”均指论文页脚印刷页码。

理解依据还包括：§2.3/2.4 的二进制跨域与仿真局限；§3/4 的两种 Gray 计数器；§5.2 的满判断；§5.3/5.4 的时钟频率与保守标志；§5.5 的复位；§12.2 的修订说明。

有意改动：

- `DSIZE/ASIZE` 改成 `DATA_WIDTH/ADDR_WIDTH`，跨域指针明确命名为 `wgray/rgray`。
- 两个方向的同步器合并为同一可复用模块，顶层对同步器宽度**显式传参**。原文 §6.1 的两个同步器实例未传入 `ASIZE`，若直接复制后只修改顶层 `ASIZE`，会与同步器默认宽度不一致。
- 满判断用“高两位掩码 XOR”表达，数学意义与原文拼接表达式相同，另支持 `ADDR_WIDTH=1`；不会产生 `[ADDR_WIDTH-2:0]` 的负下标。
- RAM 的 `write_en` 明确包含本地域复位条件。RAM 不复位内容，复位通过指针和标志使旧数据失效。
- 增加显式信号声明、参数检查、同步器属性及单独的复位同步模块。

| `rtl/style2/s2_write_ptr.sv` | 第二篇 §5.5，Example 5，正文/PDF 16 | N 位二进制/Gray 指针、满标志异步置位和两拍解除 |

理解依据还包括：§3 四象限与方向锁存；§5.3.2 复位；§5.3.6 标志置位关键路径；§5.3.7 异步控制脉冲和恢复时间讨论；§7.1/7.2 的修订和限制。

有意改动及其边界：

1. **满时保护 RAM**：原文顶层仅把 `winc` 送到 RAM 写使能，要求外部先用 `wfull` 门控。这里内部统一使用 `wrst_n && winc && !wfull`，使接口与 Style #1 一致。此修改正是第二篇 §7.2 提到但没有加入其原始代码的改进。
2. **显式 SR 锁存行为**：原文为适配当年的 LSI_10K 库，使用常量 `high` 当时钟、异步 set/reset 的特殊写法。这里用带保持分支的 `always @*` 表达方向锁存行为，避免让读者误把常量时钟技巧当通用设计模板。它仍然是异步 SR 存储元件，**没有变成普通同步逻辑**。目标器件必须另行映射、验证。
3. **读标志显式复位**：原文 `rempty` 依赖指针相等和 direction 清零后间接置位。这里把 `rrst_n` 也加入读标志控制，使复位行为明确。正常非复位期间的空标志机制不变；这是一处教学调整，不是原论文原样代码。
4. **保留 Gray 地址**：第二篇顶层将 Gray 指针直接接 RAM。原文声明但未使用的 `waddr/raddr` 不再保留，避免误导。地址顺序不是二进制自然顺序，但读写使用同一置换序列，所以 FIFO 顺序不变。
5. **没有把特殊时序风险隐藏掉**：满标志依然存在异步清零/置位混用，不能假定所有 FPGA 或 ASIC 综合库都直接支持。

第二篇 §4 的文字说比较模块没有时序逻辑，但 §5.3 的实际代码含 `direction` 存储元件。教学时应以实际行为为准：**相等比较和象限译码是组合逻辑，direction 是需要保持状态的锁存器**。

## 4. 没有照搬的内容

- 第一篇 Example 1 `beh_fifo` 是行为测试模型，论文明确不用于综合。本工程用事务级参考队列替代，不把它放进 RTL。
- 不提供未经目标工具检查的全局 false-path 模板。Gray 总线的延迟/偏斜仍需约束，不能用“异步时钟全部切掉”替代物理检查。
- 不把旧论文的特定工艺面积/性能数字推广到当前器件。
- 第二篇 §5.3.7 关于恢复时间的讨论带有作者的论证假设；本工程没有用零延迟仿真为所有真实单元背书。

## 5. 新增内容

测试平台、回归脚本、接入示例、中文教程及仿真报告均为本工程新增。测试不复制 DUT 的 Gray 满空公式：它记录**真正被接口接受的事务**，独立核对顺序、数据与容量，再辅助检查指针单比特变化。
