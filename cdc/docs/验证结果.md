# 已执行的验证结果

验证日期：2026-10-18，Asia/Shanghai。

使用本机 Siemens Questa Sim-64 2024.1，执行 `./sim/run.ps1 -Wave`。7 个 RTL 模块、完整 MCP 集成例子与自检 testbench 均参与编译。编译结果为 **Errors: 0, Warnings: 0**。

## 回归结果

每组包含两个完整 epoch，下面字数统计为两个 epoch 的实际**目的端消费数量之和**，不包括专门用于共同复位冲刷的额外活动流量。

| 配置 | MCP 字数 | 单笔 FIFO 字数 | 通用 FIFO 字数 | 事件数 | 结果 |
| --- | --- | --- | --- | --- | --- |
| fast_to_slow | 302 | 364 | 812 | 516 | PASS |
| slow_to_fast | 1337 | 1507 | 3753 | 1870 | PASS |
| coincident | 647 | 742 | 2798 | 938 | PASS |
| depth2_width1 | 497 | 593 | 1112 | 804 | PASS |
| three_stages | 406 | 465 | 1822 | 590 | PASS |
| 合计 | 3189 | 3671 | 10297 | 4718 | 5/5 PASS |

每组还执行 Gray 计数器、电平同步和复位同步检查。FIFO 定向填满验证了单笔容量与通用容量，后续变化流量覆盖背压、空/满等待及多次回绕。

总计逐笔比较 **17157 个数据字**，并对 **4718 个事件**核对接受和交付数量。所有配置末尾出现 `ALL PASS`，运行日志报告 Errors: 0。

启用调试可见性时，Questa 有 `+acc` 降低优化的提示；部分命令模式还会提示 onerror/onbreak 宜在宏中使用。已有 work 库时 vlib 提示库已存在。这些是运行设置提示，编译没有位宽、隐式信号或语法警告。

## 结论的适用范围

已验证的是随附最终 RTL 在上述参数/时钟配置下的数字功能和协议行为。没有进行真实亚稳态注入、同步周期随机扩展、形式穷举、目标器件综合、布局、门级 SDF 或 MTBF 签核。

所有双时钟通道共同复位，复位清空在途事务。不支持单侧独立复位。Gray 与 bundled-data 物理路径仍需按照 [约束要求](../constraints/README.md) 在目标工程中落实。
